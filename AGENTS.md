# AGENTS.md

This repository's agent instructions are identical for Claude Code and Codex.

1. Read `CLAUDE.md` (hard rules, commands) and `docs/PLAN.md` (full spec) first.
2. Work on one phase task at a time (see PLAN.md §16.2 / §15). Do not start the next task without the previous one's acceptance criteria passing.
3. Work on your own branch/worktree; do not edit files another agent is changing.
4. Suggested split — Codex: UI pages, satori pin templates, WordPress mu-plugin (PHP), API clients, tests. Claude Code: credit ledger, RLS, job system, topical-map pipeline and dedup, Blueprint engine, QA.
5. Finish every task with: what changed, how it was tested, what is left.
